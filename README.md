## 一、产品概述

### 1.1 核心理念

用设身处地挖掘到的痛点，以恰如其分的技术与功能去解决。技术应降低门槛，而非拉高它。

在当下高压的生活中，人们常因贷款、工作压力而忽视微小但重要的日常习惯，也缺乏自我奖励的正反馈机制。StarCard 通过任务卡片 + 星星收集 + 商城兑换的游戏化设计，让每一件小事都获得可视化的"星星"，让每一次努力都能心安理得地奖励自己。

### 1.2 核心功能

- **卡片式任务管理**：上滑删除、下滑标记重点、左右滑动切换卡片
- **每日自动生成任务**：按用户自定义模板每日凌晨创建
- **多级任务体系**：日常任务（白色）、成就任务（绿色）、官方任务（黄色）、年度任务（黑色）
- **集星商城**：用户自建商城 + 官方商城，用星星兑换奖励
- **官方任务 + 广告变现**：完成推文阅读、视频观看等获得官方星
- **消息系统**：系统通知、官方公告、官方任务推送

### 1.3 V1.0 功能范围

| 功能模块 | 是否包含 | 备注 |
|---------|---------|------|
| 任务管理（创建/完成/删除/重点标记） | ✅ | 核心功能 |
| 每日任务自动生成 | ✅ | 基于用户模板 |
| 星星收集与余额 | ✅ | 4种基础颜色 |
| 用户自建商城 | ✅ | 用户自己上架商品 |
| 官方商城 | ✅ | 兑换实物礼品 |
| 官方任务（广告） | ✅ | 推文/视频/链接 |
| 消息系统 | ✅ | 系统通知+官方推送 |

| 星星汇率兑换 | ⏳ 预留字段 | 后续版本 |

## 二、产品定位与版本策略

### 2.1 双版本策略

| 版本名称 | 定位 | 数据存储 | 目标用户 |
|---------|------|---------|---------|
| **CardStar** | 用户端发行版 | 本地存储 | 普通用户 |
| **StarCard** | 管理员版 | 实时同步服务器 | 管理员/运营 |

### 2.2 版本差异

| 功能 | CardStar | StarCard |
|-----|----------|----------|
| 任务管理 | ✅ | ✅ |
| 星星收集 | ✅ | ✅ |
| 商城兑换 | ✅ | ✅ |
| 消息接收 | ✅ | ✅ |
| 数据同步 | 本地存储 | 实时同步服务器 |

| 官方任务创建 | ❌ | ✅ |
| 官方商城管理 | ❌ | ✅ |
| 汇率设置 | ❌ | ✅ |
| 边框配置 | ❌ | ✅ |
| 卡片配置 | ❌ | ✅ |

### 2.3 数据隔离

StarCard 用户的普通任务**不会**同步到 CardStar 用户的本地数据库，需要设置保护权限。

## 五、任务系统设计

### 5.1 任务类型

| 类型 | 卡片颜色 | 星星颜色 | 来源 | 说明 |
|-----|---------|---------|------|------|
| 日常任务 | 白色 | 白色 | 每日0点自动生成 | 用户自定义模板 |
| 成就任务 | 绿色 | 绿色 | 用户手动创建 | 长期目标 |
| 官方任务 | 黄色 | 黄色 | StarCard创建推送 | 广告任务 |
| 年度任务 | 黑色 | 黑色 | 用户手动创建 | 年度目标 |

### 5.2 任务生命周期

```
创建任务 → task_queue（待完成）
    ↓
完成 → completed_tasks（已完成）→ 星星到账
    ↓
逾期 → overdue_tasks（逾期）→ 可恢复
    ↓
删除 → 彻底删除（弹窗确认）
```

### 5.3 创建任务

#### 入口
- 首页右下角悬浮「+」按钮

#### 创建弹窗字段

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| 任务内容 | 文本 | ✅ | 任务描述 |
| 截止日期 | 日期 | ❌ | 默认当天 |
| 任务类型 | 单选 | ✅ | 日常/成就/年度 |
| 奖励数量 | 数字 | ✅ | 星星数量 |

#### 自动生成字段

| 字段 | 说明 |
|-----|------|
| 任务ID | 自动生成唯一ID |
| 创建时间 | 自动记录 |
| 卡片颜色 | 根据任务类型自动设置 |
| 排序位置 | 新任务添加到队尾 |

### 5.4 每日任务自动生成

- **触发时间**：每日凌晨0点
- **来源**：用户自定义模板
- **生成规则**：根据模板中的任务内容、奖励数量等自动创建白色卡片任务

### 5.5 任务排序

- **左右滑动**：将当前卡片移至队尾，下一张卡片显示
- **排序同步**：
  - StarCard：实时同步到服务端
  - CardStar：本地缓存
- **新任务位置**：添加到队尾

### 5.6 逾期任务处理

- **触发条件**：超过截止日期未完成
- **处理方式**：自动移入 overdue_tasks 表
- **恢复后**：
  - 保持原截止日期
  - 完成后在已完成列表中，完成日期显示为红色（正常完成为黑色）

## 六、星星系统设计

### 6.1 星星类型

| 星星颜色 | 获取方式 | 稀有度 | 用途 |
|---------|---------|-------|------|
| 白色星 | 完成日常任务 | 普通 | 兑换基础奖励 |
| 绿色星 | 完成成就任务 | 稀有 | 兑换高级奖励 |
| 黄色星 | 完成官方任务 | 稀有 | 兑换官方商品 |
| 黑色星 | 完成年度任务 | 极稀有 | 兑换特殊奖励 |

### 6.2 星星获取

- **触发时机**：点击任务完成按钮后立即自动到账
- **数量计算**：基础奖励 × 边框权重加成（如有）

### 6.3 星星余额查看

- **入口**：「我的」页面 → 星星余额 → 点击进入星星页面
- **显示内容**：各色星星的当前余额

### 6.4 星星汇率（预留）

- **V1.0状态**：不开放兑换
- **管理员设置**：StarCard可设置汇率
- **兑换规则**（后续版本）：只能珍贵星换普通星，不可反向兑换（避免刷星）

### 6.5 扩展性

支持后续添加联名专属星星，作为独立数据表存储。

## 八、消息系统设计

### 8.1 消息类型

| 类型 | 可删除 | 说明 |
|-----|-------|------|
| 系统通知 | ✅ 可一键清除 | 任务到期、逾期提醒 |

- 任务类消息（系统通知）- 可一键清除

### 8.4 官方任务推送

- **来源**：StarCard创建官方任务后，推送到CardStar用户
- **任务类型**：推文阅读、视频观看、链接跳转等

| 卡片配置 | 上架/下架新任务卡片及其兑换星 |

### 10.3 数据权限

- StarCard用户的普通任务**不会**同步到CardStar用户的本地数据库
- 需要设置保护权限，避免数据混淆
